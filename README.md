# Pinenest · 松木设计

基于 Forma Studio 的页面结构、版式、黑白配色和交互节奏，融合松木设计原网站的项目、图片和品牌文案。

## 本地运行

需要 Node.js 20 或更新版本，不需要安装第三方依赖。

```sh
npm run dev
```

默认地址为 `http://localhost:4173`。端口已占用时可使用 `PORT=4186 npm run dev`。

```sh
npm run build
npm run check
```

构建输出位于 `dist/`，可部署至支持静态目录路由的托管服务。使用 `/404.html` 作为错误页面。

## Netlify 部署

项目名称：`pinenest-design`。构建配置保存在 `netlify.toml`，构建命令为 `npm run build && npm run check`，发布目录为 `dist`。

首次部署使用本地构建后的静态文件上传，未连接 Git 仓库自动发布。后续可以重新构建并上传 `dist`，或连接代码仓库后由 Netlify 自动构建。

站点绝对资源地址依次使用 `SITE_URL`、Netlify 提供的 `URL` 环境变量，默认是 `https://pinenest-design.netlify.app`。绑定自定义域名后重新构建即可更新分享图片地址。

## 内容与文件

- `content/projects.json`：六个项目的中英文内容、年份、地点、面积、设计说明与图片信息。
- 金茂·黄金海岸的 `comparisons` 指定七组改造前后照片；详情页按左前右后展示，桌面和手机均保留双栏，照片完整显示并可放大。
- `public/assets/`：本地 WebP 项目照片、品牌标志、字体，以及参考站的流程示意图。
- `scripts/build.mjs`：生成首页、关于、作品集、六个项目详情、联系和隐私说明。
- `src/styles.css`：桌面及手机版式、滚动与悬停效果。
- `src/app.js`：语言切换、分类筛选、图片查看、FAQ、理念轮播、微信二维码气泡和在线咨询。

原始内容来自 https://pinenest.figma.site/ 及六个项目详情页。项目面积按详情页记录；详情页与首页存在差异时采用详情页信息。新增的设计说明和服务文案围绕原项目内容撰写，没有添加虚构的客户评价、奖项或联系电话。

视觉参考：https://formastudio.framer.ai/ 。作品摄影均来自松木设计旧站；流程图是设计流程的通用示意，不作为松木项目图纸使用。

## 联系流程

全站微信入口点击后展示 `public/assets/wechat.jpg` 原图，支持关闭、点击外部关闭、Escape 关闭、保存二维码以及移动端查看。

咨询表单通过 Netlify Forms 接收，表单名为 `project-enquiry`，通知邮箱为 `1291362786@qq.com`。已在 Netlify 后台启用 Form detection，并在 Forms → Submission notifications 配置新咨询邮件通知；重新创建 Netlify 项目时需同步设置。访客提交姓名、联系方式、选填邮箱及项目需求后，页面展示提交结果；发送失败时保留输入并支持重试。邮件的 Reply-To 使用访客选填的 `email` 字段。

咨询内容会保存在 Netlify 表单后台，并由平台转发邮件；前端不保存邮件密钥。中英文偏好使用 `localStorage` 保存。隐私说明已同步描述表单收集和邮件转发流程。本地预览服务器仅提供静态文件，不接受真实咨询提交。
